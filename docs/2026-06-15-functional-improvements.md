# 기능 개선 구현 기록 (2026-06-15)

"행정전화부"(광주광역시 동구) 명칭 변경과 함께, 대규모 명부 사용성 위주의 기능을 구현했다.
모두 순수 바닐라 JS(no-build), 데이터는 로컬에서만 처리한다.

## 명칭/아이덴티티
- [x] 비상연락망 → **행정전화부** (타이틀/manifest/백업 파일명/오류 메시지/README)
- [x] 앱 아이콘 → **"동구" 한글 워드마크**(광주광역시 동구). `tools/make_icons.py`가 Pillow+CJK 폰트로 생성
      (이전 인물/비상 모티브 대체). 공식 휘장은 동일 크기 PNG 교체로 대응 가능

## 탐색성 (부서·가나다)
- [x] **정렬 전환** — 부서순 ↔ 가나다순 세그먼트 컨트롤 (`#list-tools`)
- [x] **부서 빠른 이동** — 상단 부서 칩(`#dept-nav`), 탭 시 해당 섹션으로 스무스 스크롤(접힌 부서는 펼침)
- [x] **부서 섹션 접기/펼치기** — 섹션 헤더 버튼(`aria-expanded`, chevron 회전)
- [x] **가나다 뷰 + 인덱스 레일** — 초성 그룹핑(`Data.groupedByName`), 우측 ㄱㄴㄷ 레일(`#alpha-rail`)로 점프
- [x] **검색어 하이라이트** — 일치 글자 `<mark>` 강조(이름/부서·팀·직책), 노드 조립으로 XSS 안전

## 연락 동작
- [x] **전화번호 복사** — 상세 각 번호 행에 복사 버튼(`navigator.clipboard` + execCommand 폴백)
- [x] **연락처 공유** — `navigator.share`(미지원 시 텍스트 복사 폴백)
- [x] **vCard 저장** — `.vcf` 다운로드로 기기 주소록에 추가(로컬 파일)
- [x] **스낵바** 피드백(복사됨/저장됨) — `#snackbar`

## 비고
- `UI.renderRow`/`renderFlat` 등은 옵션 객체(onOpen/onFav/query) 기반으로 정리.
- SW 캐시 `donggu-dial-v5`.
- 향후: 부서 대표번호/위치(데이터 확장), 다중 전화번호, 데이터 최신화 표기(P2) 후속 가능.
